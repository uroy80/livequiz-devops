# LiveQuiz – Real-time Classroom Quiz Platform
**Major Project · 21IPE333P Essentials in Cloud and DevOps · Usham Roy (RA2311003011574)**

A dynamic, real-time quiz web app (hosts create quizzes, players join from their phones with a PIN or QR code,
answers and leaderboards update live over WebSockets, results are stored in PostgreSQL) –
deployed to **AWS** with **one click in Jenkins**.

## One-click pipeline
```
Click "Build Now" in Jenkins (or git push)
  → Jenkins pulls this repo from GitHub
  → unit + integration tests, lint
  → Docker image built and scanned with Trivy
  → Terraform provisions AWS: VPC, subnet, IGW, security group, IAM role, EC2 (Graviton), Elastic IP, ECR, CloudWatch logs + alarms
  → image pushed to Amazon ECR
  → Ansible configures the server (Docker, ECR credential helper) and deploys app + PostgreSQL with Docker Compose
  → smoke test of the public URL (health, API, WebSocket handshake)
  → live URL printed
```
`LiveQuiz-Destroy` removes every AWS resource with one click.

| Requirement | Used |
|---|---|
| AWS Cloud | EC2 (t4g.small), VPC, Elastic IP, ECR, IAM role + instance profile, CloudWatch Logs + alarms |
| Git | GitHub repo, Jenkins polls it – every push redeploys |
| Jenkins | Docker-based controller, configured as code (JCasC + Job DSL), `Jenkinsfile` |
| Terraform / Ansible / Docker | all three |
| Dynamic app | Flask + Socket.IO + PostgreSQL, accounts, live games, stored results |

## Layout
| Path | What |
|---|---|
| `app/` | LiveQuiz (Flask, Flask-SocketIO, SQLAlchemy), tests, Dockerfile |
| `infra/terraform/` | AWS infrastructure as code |
| `infra/ansible/` | server configuration + deployment (roles `docker`, `livequiz`) |
| `jenkins/` | Jenkins image, JCasC, Job DSL |
| `Jenkinsfile`, `Jenkinsfile.destroy` | the one-click pipelines |
| `demo.sh` | `jenkins` · `deploy` · `url` · `status` · `destroy` · `stop` |

## Run
```bash
./demo.sh jenkins     # start Jenkins on http://localhost:8088
./demo.sh deploy      # the one click (or press Build Now on LiveQuiz-Deploy)
./demo.sh url         # live URL + host login
./demo.sh destroy     # remove everything from AWS
```
Local only: `docker compose up --build` → http://localhost:8200

Security: no secrets in git – passwords are generated by Terraform, written by Ansible into a root-only `.env`
on the server; the server pulls from ECR with its IAM role; SSH is open only to the Jenkins host's IP; IMDSv2 only; encrypted disk.
