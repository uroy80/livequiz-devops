# LiveQuiz – Live Demo Cheat Sheet (Major Project)

```bash
cd ~/Desktop/dev/LiveQuiz-Major-Project
```

## Before the professor arrives (≈5 min)
```bash
aws login                 # AWS session lasts 12 hours
./demo.sh jenkins         # Jenkins → http://localhost:8088  (admin / cat .secrets/jenkins-admin-password)
./demo.sh status          # is the app already deployed?
```
If it is **not** deployed, you can do the one click live (best) – it takes ~2.5 minutes.

## The demo (10 minutes)
| Step | Say | Do |
|---|---|---|
| 1 | "Everything is in Git." | Open https://github.com/uroy80/livequiz-devops – show `Jenkinsfile`, `infra/terraform`, `infra/ansible`, `app/` |
| 2 | "One click deploys it to AWS." | Jenkins → **LiveQuiz-Deploy → Build Now** (or `./demo.sh deploy`). Open the build's *Pipeline Overview* and narrate the stages |
| 3 | "Terraform is creating the AWS infrastructure." | Point at stage 5: VPC, EC2, ECR, IAM, CloudWatch being created |
| 4 | "Ansible configures the server and deploys Docker containers." | Stage 7 tasks |
| 5 | "It's live." | `./demo.sh url` → open the URL, log in as **admin** with the printed password |
| 6 | **"Please scan this QR code."** | My quizzes → *DevOps & Cloud Challenge* → **Host live**. Show the QR on the projector; everyone joins with their phones and plays |
| 7 | "Every push redeploys automatically." | Edit something small (e.g. `VERSION` → 1.1), `git commit -am "v1.1" && git push` – Jenkins starts by itself within 2 min; footer shows the new build |
| 8 | "One click removes everything." | **LiveQuiz-Destroy** → Build with Parameters → type `destroy` (or `./demo.sh destroy`) |

## Viva quick answers
- **State?** Terraform state is kept in Jenkins (`/var/jenkins_home/state`), so Destroy deletes exactly what Deploy created.
- **Secrets?** Generated by Terraform, written by Ansible to a root-only `.env`; never in Git. EC2 pulls from ECR with its IAM role – no passwords.
- **Why WebSockets?** Server pushes each question/result to all phones instantly.
- **Security gate?** Trivy blocks vulnerable images before anything reaches AWS (it really did in build #2).

## After the demo
```bash
./demo.sh destroy     # always – stops AWS billing
./demo.sh stop        # stops Jenkins
```
